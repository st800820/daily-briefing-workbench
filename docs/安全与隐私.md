# 安全与隐私规则（开源必读）

本项目开源版**已移除原作者全部私有配置**。无论你是部署者、二开者还是贡献者，请严格遵守以下规则，避免密钥泄露带来真实损失。

---

## 一、哪些文件含隐私 / 运行产物（绝不入库）

| 文件 / 目录 | 内容 | 处理 |
|---|---|---|
| `config.json` | 真实密钥、Webhook、城市、过滤词 | **不提交**（已忽略） |
| `config_local.py` | 本地覆盖配置（常含密钥） | **不提交**（已忽略） |
| `*.log`、`logs/` | 运行日志（可能含内容片段） | 不提交 |
| `output/`、`data/`、`last_push.txt` | 生成产物 / 去重记录 | 不提交 |
| `.env`、`.env.*` | 环境变量密钥 | 不提交 |

> 仓库内只保留 `config.example.json`（占位，**无真实值**）。

---

## 二、提交前自检清单

1. **确认 `.gitignore` 已包含上述文件**（本仓库已配好）。
2. **全局搜索真实密钥**（任何分支、任何文件）：
   ```bash
   grep -rE "AT_|SPT_|SCT|webhook/send\?key|access_token|SEC[a-f0-9]{8}" . --include=*.py --include=*.json --include=*.yml --include=*.md
   ```
   若搜到真实值，先替换为占位符再提交。
3. **检查 Git 历史**：即使本次没提交，若以前提交过密钥，历史里仍有。务必先吊销再清理历史（见第三节）。
4. **不要**在 Issue / PR / 评论 / README 示例里粘贴真实 token、webhook、secret。

---

## 三、密钥一旦泄露：立即吊销

| 通道 | 吊销 / 重置位置 |
|---|---|
| WxPusher | WxPusher 后台重置 appToken / 极简 token；撤销旧 UID 授权 |
| 企业微信机器人 | 企业微信后台删除该机器人，重新创建拿新 `key` |
| 钉钉机器人 | 钉钉群机器人设置里"删除"或"重新获取"Webhook / Secret |
| 聚合数据 Weather Key | 聚合数据控制台重置 Key |
| Anspire Key | Anspire 开放平台重置 |

> 泄露的密钥**无法仅通过删除文件挽回**——必须重置，因为克隆者可能已拿到。

---

## 四、运行安全

- **后台端口不要裸奔公网**：网页后台（12345）可改所有密钥与定时。若需外网访问，请：
  - 用反向代理（Nginx / Caddy）+ HTTPS；
  - 设置 `ADMIN_PASSWORD`（通过环境变量注入，**不要明文写死**在 `docker-compose.yml`）；
  - 或仅暴露给 VPN / 内网。
- **环境变量注入示例**（而非写死）：
  ```yaml
  environment:
    - ADMIN_PASSWORD=${ADMIN_PASSWORD}   # 来自宿主机环境变量 / .env（.env 不入库）
  ```
- **定期轮换**：建议每季度轮换一次各通道密钥。
- **最小权限**：钉钉机器人按需开启加签；企业微信机器人只放进必要群。

---

## 五、贡献者须知

- 提交 PR 前，确保 diff 里**没有任何真实密钥**。
- 若发现他人误提交密钥，请提醒其在合并前重置并改写历史（不要只删文件）。
- 文档示例一律使用 `AT_你的token`、`你的key` 等占位符。
